# effect-lib

Small [Effect](https://effect.website) building blocks in one package, one subpath export each: credentials, deploying a Worker with alchemy, JSON files, OpenAI images, pulse, Pushover notifications, OpenRouter speech-to-text, systemd user services and Tailscale Serve.

## Requirements

- [Bun](https://bun.sh)
- `effect` 4.1 or later, a peer dependency

## Installation

```sh
bun add github:laroccacharly/effect-lib#<tag> effect@^4.1
```
